## 2024-05-24 - [Title] **Duplication:** Found scattered repetitive calls to `println!("{}", serde_json::to_string(&...)?);` throughout all `commands_*.rs` files for emitting JSON payloads to standard output. **Learning:** Agents implementing JSON outputs repeatedly hand-rolled JSON formatting and stdout emission instead of using a unified wrapper, likely due to a missing standardized IO helper for `--json` outputs. **Abstraction:** Introduced `emit_json<T: Serialize>(payload: &T) -> Result<()>` in `crates/pebble/src/commands.rs` to wrap serialization and stdout writing, providing a cleaner, reusable API across the entire CLI.
