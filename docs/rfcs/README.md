# RFCs (Archived Design Decisions)

These documents are **frozen snapshots** of design proposals made at a
specific point in time. They are preserved for historical context only.

**Do not treat these as authoritative specifications.** The live,
canonical documents are:

- [cli-contract.md](../cli-contract.md) — Interface Layer
- [schema.md](../schema.md) — Data Layer
- [graph-semantics.md](../graph-semantics.md) — Logic Layer

Each RFC carries a `[STATUS: FROZEN]` header to reinforce this.
