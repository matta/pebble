---
name: Keep Specifications Updated
description: Keep the specifications up to date with code
---
Keep normative specifications (`docs/*.md` and non-frozen `docs/rfcs/*.md`) up to date with the code.

If you make a change to the code, update the normative specifications to match.

If you make a change to the normative specifications, update the code to match.

Frozen RFCs (`docs/rfcs/` files marked as frozen) are historical records preserved for context only. They are expected to diverge from the current code and specifications over time. Do not modify frozen RFCs, and do not flag code as inconsistent with a frozen RFC.
