---
name: Keep Specifications Updated
description: Keep the specifications up to date with code
---
Keep `docs/*.md` and `docs/rfcs/*.md` up to date with the code.

If you make a change to the code, update the specifications to match.

If you make a change to the specifications, update the code to match.

Modifications to frozen specifications are not allowed, and must be rejected. This implies that a frozen specification is allowed to be out of sync with the code.
